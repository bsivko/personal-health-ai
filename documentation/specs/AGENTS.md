- [prepare-visit.md](prepare-visit.md) — appointment preparation; R-003.

For each operation describe inputs, results, uncertainty handling, and verification. Record confirmed changes to boundaries in `../DECISIONS.md`; a specification alone does not prove an operation works.

All stages and checks are mandatory for an ordinary user request. The user need not list them, supply technical fields, or separately ask for verification. The agent performs the checks and reports their limitations.
