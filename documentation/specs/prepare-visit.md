# Preparing for a doctor's appointment

Status: provisional contract. Requirement: R-003 in [REQUIREMENTS.md](../REQUIREMENTS.md).

## Input
Clinician specialty, purpose, appointment date if available, and available materials. If purpose is unknown, state the limitation and prepare a general version or ask for necessary clarification.

## Result
A dated document or package in outputs:
- Short summary of the reason for the visit and relevant information.
- Timeline of symptoms, examinations, and treatment from available sources.
- Important measurement trends with units and reference ranges.
- Prescriptions, actual intake, and allergies within available coverage, with unknowns explicit.
- Questions for the clinician and data gaps/conflicts.
- Used-material list and available attachments.

## Verification
Ensure the short section is understandable without all attachments, each important claim has evidence, and required originals are available. Separate user reports and document conclusions from analytical hypotheses. Do not describe prescribed medication as actually taken.

The package is a snapshot of the data used. Updates preserve version links, dates, and changed evidence.

## Practical contract verification
Prepare a summary for a specific visit from real materials, then verify completeness, readability, and evidence navigation with the user. Suitability for a specialist is not yet confirmed.
